# Release Checklist

- [ ] Roadmap screens and backend dependencies approved; no mock financial/product data ships.
- [ ] `bun run validate`, `npx expo install --check`, Expo Doctor, dependency/secret audits pass.
- [ ] iOS/Android release builds pass critical E2E, accessibility, large-text, theme, and offline tests.
- [ ] Startup, lists, media, memory, bundle, slow-network, background/restore performance accepted.
- [ ] Auth rotation/logout, roles/permissions, deep links, push, payment callbacks, idempotency and ambiguous results reviewed.
- [ ] Production URL/certificates, EAS signing/profiles/channels/runtime/rollback and forced-update policy verified.
- [ ] Permission strings, platform privacy manifests, store privacy disclosures, legal/support URLs approved.
- [ ] Icons, adaptive/monochrome icon, splash and status/navigation bars verified in release builds.
- [ ] Backend migrations, deterministic seeds, monitoring, alerting, rate limits, audit and incident runbook ready.
- [ ] Analytics/crash logs are consent-aware and redacted; notification payloads contain no sensitive data.
- [ ] Store metadata, screenshots, ratings, review credentials, staged rollout and rollback owner ready.
- [ ] Known limitations, owners, acceptance, build identifiers and sign-off date recorded below.
